📁 나이스 파일 업로드

나이스 → 학교생활기록부 → 교과학습발달상황 엑셀 파일을 선택하세요.
반별 파일을 여러 개 동시에 올릴 수 있습니다.
한 파일에 여러 학년(1학년~현재)의 누적 성적이 들어있어도 학년·학기가 자동으로 인식되어 분리됩니다.

전과목 성적 일람표 엑셀 파일 선택

나이스 → 성적처리 → 전과목 성적 일람표 → 엑셀 저장
📐 가등급 기준 (5등급제)
1등급 ≤ 상위 10% 2등급 ≤ 상위 34% 3등급 ≤ 상위 66% 4등급 ≤ 상위 90% 5등급 그 외

반별 블록이 반복되는 형태의 등급표 / 성취도표 / 원점수표 3개 엑셀 파일을 각각 선택하세요.
나이스 파일과 학기 이름이 같으면 자동으로 같은 학기에 합쳐집니다.
